# Conformal Prediction Sets — ES 678 Course Project

**How Small Can a Trustworthy Prediction Set Be? Score Design and Class-Conditional Coverage in
Conformal Classification**

This repo wraps a fixed image classifier with **conformal prediction** to produce label *sets* that
contain the true class with probability `≥ 1 − α`, then studies the **efficiency** (set size) and
**class-conditional coverage** of different conformity scores — including a proposed
temperature-scaled, Mahalanobis-augmented score.

- [`PROPOSAL.md`](./PROPOSAL.md) — the proposal (problem, data, methods, evaluation, depth component).

## Pipeline
```
data → model → calibrate (temperature) → scores → conformal → evaluate → plots
```

## Key rule (validity)
`T`, `γ`, RAPS `λ,k_reg` and all method selection use the **design** split (`D_design`).
The conformal quantile `q̂` uses the **calibration** split (`D_cal`) only.
`D_test` is opened once, for the final table. Mixing these **breaks the coverage guarantee**.

## Data
All datasets load from `torchvision` (public, no access limits):
MNIST · CIFAR-10 (in-distribution) · FashionMNIST, KMNIST, SVHN, CIFAR-100 (OOD).
